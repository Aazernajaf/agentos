# Active task brief

Use in chat for ordinary multi-step work; copy to an ignored `work/` file only when continuity benefits. Put a sanitized final handoff in `docs/handoff/` when useful. Do not copy private messages, transcripts, account details or credentials.

- **Objective:** requested user outcome.
- **Scope:** included areas and explicit exclusions.
- **Acceptance criteria:** observable conditions that establish completion.
- **Authorization:** permitted actions, existing approvals and boundaries that still require approval.
- **Verified state:** branch/revision, relevant input versions and current working-tree observations.
- **Completed work:** result/evidence pointers; avoid replaying the whole conversation.
- **Checks:** command, result, revision/inputs, remaining coverage and reason for any skipped check.
- **Current step / next action:** one concrete authorized action.
- **Pending decision:** exact missing information and dependent work held.
- **Queued ideas:** separate additions and whether a new chat was suggested/requested.
- **Status:** active, waiting on a named dependency, explicitly paused, superseded or complete. Do not mark complete merely because an intermediate question was answered.
