# agentos-session-flow

Read the [operating policy](../../../docs/agents/operating-policy.md) and [own SOP](SOP.md). Preserve the current objective through incidental questions, distinguish steering from cancellation, and suggest a separate chat only for useful independent work. Do not create chats, delegate or start added work merely because it was suggested.
